===============================================================
SLOT FOTO RUANGAN LOKAL (MEETING ROOM SYSTEM)
===============================================================

Folder ini (public/rooms/) disediakan untuk meletakkan file foto ruangan fisik Anda secara lokal.

Format & Nama File yang telah dipetakan secara default di sistem:
1. Ruang Rapat Kalibaru Timur (R-KBT)    -> public/rooms/r-1.jpg
2. Ruang Rapat Kalibaru Barat (R-KBB)    -> public/rooms/r-2.jpg
3. Ruang Rapat Samudera (R-SMD)          -> public/rooms/r-3.jpg
4. Ruang Rapat Nusantara (R-NST)         -> public/rooms/r-4.jpg
5. Ruang Rapat Pelabuhan Dalam (R-PLD)   -> public/rooms/r-5.jpg
6. Ruang Rapat Pelra (R-PLR)             -> public/rooms/r-6.jpg

Tips:
- Format yang didukung: .jpg, .jpeg, .png, .webp
- Ukuran rekomendasi: Resolusi 800x600 hingga 1920x1080 (rasio 4:3 atau 16:9)
- Anda juga dapat mengganti nama slot foto atau mengunggah langsung dari menu Admin: "Manajemen Ruangan" -> tombol "Foto / Slot".
